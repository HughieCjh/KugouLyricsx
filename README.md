# KugouLyricsx

一个非官方的 macOS 菜单栏小工具：读取酷狗音乐正在播放的歌曲，在配备 Touch Bar 的 MacBook Pro 上显示卡拉 OK 式逐字歌词，并提供上一曲、播放/暂停、下一曲按钮。

## 功能

- Touch Bar 显示当前一句歌词，已唱部分以亮蓝色从左向右平滑覆盖
- 读取酷狗 KRC 的逐字时间，当前字也会显示连续的颜色推进
- 自动学习酷狗真实换句间隔，逐句修正不同歌曲版本造成的逐字快慢偏差
- 可选左右双句模式：一侧播放当前句，另一侧始终预览下一句并交替切换
- Touch Bar 空心细线图标快捷控制：上一曲、播放/暂停、下一曲
- 菜单栏显示当前歌曲与当前歌词
- 拖动酷狗进度条后，歌词会重新校准到新的播放位置
- 优先识别酷狗发布给 macOS 的实时歌词，避免同名歌曲和不同版本错配
- 自动过滤 KRC 中的制作信息，并在间奏期间清空歌词
- 优先读取酷狗本地 KRC 歌词，离线也可使用已缓存歌词
- 本地无歌词时，尝试网易云音乐和 LRCLIB 的公开歌词接口
- 支持歌词时间偏移微调（菜单栏内每次 ±0.25 秒）
- 可选择在酷狗播放期间保持主屏幕常亮

## 与 LyricsX 的关系

KugouLyricsx 是一个针对酷狗音乐独立开发的 macOS 工具，不是 LyricsX 的插件、补丁、分支或修改版。项目没有复制或修改 LyricsX 的源代码，运行时也不需要安装 LyricsX。

两者只是目标相似：都读取 macOS 的“正在播放”信息，并在 Touch Bar 上提供同步歌词体验。KugouLyricsx 的 Touch Bar 界面、歌词解析与同步、酷狗识别、播放控制和防熄屏功能均在本项目中独立实现。

项目随包使用的第三方组件是 `media-control / mediaremote-adapter`，用于读取 macOS 媒体状态和发送播放命令；它不是 LyricsX 的组件，许可信息见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 系统要求

- **macOS 13 Ventura 或更高版本**。低于 macOS 13 的系统不能运行当前版本。
- **Apple 芯片（arm64）或 Intel（x86_64）Mac**。当前发布包的主程序和随附媒体控制组件均包含两种架构。
- **实体 Touch Bar**。没有 Touch Bar 的 Mac 可以启动菜单栏程序，但无法使用本项目的核心歌词与控制界面。
- **酷狗音乐 Mac 版**，并且酷狗需要能够向 macOS 发布“正在播放”信息。
- 在线搜索歌词时需要网络；已缓存的酷狗本地歌词不需要网络。

此前完整播放测试环境：MacBook Pro（M2，Mac14,7）、macOS 15.6.1、酷狗音乐 3.3.2。新版酷狗音乐 20.3.8 的媒体信息与本地歌词缓存已核对，仍需继续进行完整 Touch Bar 播放验证。

Intel Touch Bar Mac 尚未进行真机测试。其他 Touch Bar 机型及较新的 macOS 版本也尚未逐一测试。Touch Bar 使用了系统私有接口，未来的 macOS 更新可能改变其行为。

## 安装

1. 打开 `KugouLyricsx-0.4.3.dmg`。
2. 将 `KugouLyricsx` 拖入“应用程序”。
3. 启动酷狗音乐并播放歌曲，再打开本应用。

如果安装过旧名称 `KugouTouchBarLyrics.app`，请先退出旧版本并将它从“应用程序”移除，避免新旧两个菜单栏程序同时运行。改名后的版本会被 macOS 视为新的 App，原来的“播放时保持主屏幕常亮”开关需要重新设置一次。

### 是否需要允许“任何来源”

**不需要，也不建议开启“允许任何来源”。** 不需要关闭 SIP，不需要关闭 Gatekeeper，也不需要在终端执行全局解除安全检查的命令。

当前发布包采用临时签名，没有 Apple Developer ID 签名和 Apple 公证，因此首次启动可能被 Gatekeeper 拦截。请只为这个 App 添加一次例外：

1. 确认 App 来自本项目可信的 GitHub 仓库或 Release 页面，并已拖入“应用程序”。
2. 先正常打开一次；如果 macOS 阻止运行，关闭提示窗口。
3. 打开“系统设置 → 隐私与安全性”，向下滚动到“安全性”。
4. 找到被阻止的 `KugouLyricsx`，点击“仍要打开”，然后按系统提示确认。该按钮通常只会在尝试启动后的一段时间内出现。
5. 以后可以像普通 App 一样直接打开，无需重复操作。

也可以先在 Finder 中按住 Control 键点按 App，选择“打开”，再在确认窗口中选择“打开”。不同 macOS 版本显示的文字可能略有不同。Apple 官方说明见：[打开来自未知开发者的 Mac App](https://support.apple.com/zh-cn/guide/mac-help/-mh40616/mac)。

如果 Mac 由公司或学校管理，“仍要打开”可能被管理员策略禁用；这种情况下需要联系管理员。本应用不需要管理员权限、屏幕录制权限或完全磁盘访问权限。只有“酷狗窗口位于前台时同步进度条拖动”需要辅助功能权限，原因和开启方法见下一节。

### 辅助功能权限

酷狗窗口位于前台时，拖动进度条不会把新位置发布给 macOS 的“正在播放”接口。为了让 Touch Bar 歌词仍能立即跳到新位置，KugouLyricsx 会通过 macOS 辅助功能接口，只读获取酷狗底部已经公开的当前播放时间标签。

首次启动新版时，macOS 会提示授权。也可以点击菜单栏中的“酷狗进度同步：点击授权辅助功能”，然后在“系统设置 → 隐私与安全性 → 辅助功能”中开启 `KugouLyricsx`。授权后菜单会显示“酷狗进度同步：已启用”。如果刚开启后没有立即生效，请退出并重新打开 KugouLyricsx。

不授权也可以继续使用歌词、播放按钮、歌词偏移和常亮功能；但酷狗窗口位于前台时拖动进度条可能无法同步，切换到桌面或其他应用后，macOS 重新发布播放位置时才可能恢复。

## 使用

Touch Bar 从左到右显示：

`上一曲 | 当前一句歌词 | 播放/暂停 | 下一曲`

三个播放控制按钮使用圆角空心细线图标：上一曲为 `|<`，下一曲为 `>|`；播放按钮会根据酷狗当前状态自动切换为空心播放三角或暂停双线。

这些图标由 Objective-C 使用 `NSBezierPath` 绘制为 22pt 矢量路径，再以 2x 分辨率渲染成白色非模板图片，放入 44pt 的原生 Touch Bar 按钮。使用非模板图片是为了避免系统模态 Touch Bar 将白色模板错误地重新着色为黑色。

菜单栏图标中可以查看当前歌曲、调整歌词时间偏移，或退出应用。勾选“左右双句歌词”后，中间区域会分成左右两栏并留出空白间隔：一边逐字播放当前句，另一边以灰色预览下一句；当前句结束后，预览侧开始播放，原播放侧立即刷新为再下一句，两边持续交替。取消勾选即可恢复单句居中模式，选择会自动保存。

同步区域提供“延后 3 秒”到“提前 3 秒”的连续滑杆，拖动时以 0.05 秒为单位即时更新 Touch Bar，并显示当前数值；也可以使用下方的 ±0.25 秒按钮精调或一键重置。偏移量同时作用于换句和逐字颜色：设置“提前”后，下一句会提前成为当前句并立即从第一个字开始变蓝，另一侧同步刷新后续预览。偏移量会自动保存，下次启动继续使用。切歌后程序会自动重新查找歌词；授予辅助功能权限后，在酷狗前台拖动进度条通常会在约 1 秒内跳到对应歌词。

Touch Bar 动画定时器运行在 macOS 的通用交互模式中，因此在打开菜单、拖动同步滑杆或操作酷狗进度条期间也会继续刷新，不需要再点击桌面唤醒。

部分酷狗歌曲会通过 macOS 媒体信息动态发布当前歌词。KugouLyricsx 会监听这条实时媒体事件流，在酷狗换句时立即取得与菜单栏相同的文字；实时文字始终作为当前句，本地 KRC 只提供逐字节奏和下一句预览，不会反过来用本地行覆盖酷狗当前句。普通的一秒播放状态校准仍会处理暂停、继续和拖动进度条。

酷狗偶尔会在同一个媒体字段中穿插歌手、作词、作曲、乐队和制作人员信息。歌曲开头尚未出现第一句真实歌词时，这些介绍会按照酷狗发送的顺序完整显示；第一句歌词出现后，作者和制作人员信息不再插入歌词，也不会进入左右双句预览。暂停时会锁定当前播放位置；如果酷狗紧接着在相同位置误报“正在播放”，程序会忽略该事件，直到播放位置真正继续移动或用户主动点击播放。

逐字颜色并不是通过屏幕截图识别。程序从酷狗本地 KRC 缓存读取每个字的开始时间和持续时间，再把时间套用到酷狗实时发布的当前文字：未唱部分为浅灰色，已唱部分为亮蓝色，当前字内部也会平滑推进。即使本地 KRC 是同一首歌的短版，只要当前文字能够匹配，程序也会以酷狗换句时刻重新锚定相对字时长，减少不同版本造成的整体延迟。

逐字速度会在当前歌曲的播放过程中自适应：程序记录酷狗两次真实换句之间的播放时间，将它与对应 KRC 片段的字时长比较，并用平滑方式修正这一句的播放速度。同一句或重复副歌再次出现时通常会更准确；第一次出现仍可能有轻微快慢误差。暂停不会产生错误样本，拖动进度条会取消被打断的本次测量，但保留已经学到的速度；切歌或退出应用后学习结果会清空。异常短、异常长或比例明显不合理的样本会被自动忽略。自适应速度本身只使用已有媒体时间；辅助功能权限仅用于识别酷狗前台的进度条拖动。

如果歌曲没有本地 KRC、KRC 不含逐字标签，或者当前实时文字无法匹配，程序会保持整句可读并退回逐句显示，不会为了动画强行套用错误时间。歌曲与 KRC 时长不一致时，以酷狗实时文字为准；只有设置了“歌词提前”时才会短暂预显示 KRC 中可确认的后续句，酷狗发布真实下一句后立即重新校准。句间不会插入音符图标；歌曲开头的制作介绍正常显示，进入歌词阶段后再出现的制作信息会留空。

“播放时保持主屏幕常亮”默认关闭。开启后，设置会被保存；只有酷狗正在播放时才阻止主屏幕因空闲休眠，暂停、退出酷狗或退出本应用后会自动恢复系统休眠行为。该功能使用 macOS 的电源断言，不需要辅助功能权限；开启会增加电池消耗。

Touch Bar 有独立于主屏幕的硬件空闲策略。macOS 没有向普通第三方应用开放“阻止 Touch Bar 空闲熄灭”的接口，因此本应用无法保证 Touch Bar 始终点亮。Touch Bar 熄灭后，触碰键盘或触控板即可恢复，歌词仍会继续同步。

## 从源码构建

先安装 Xcode Command Line Tools，然后在项目目录执行：

```sh
xcode-select --install
make release
```

生成文件：

- `dist/KugouLyricsx.app`
- `dist/KugouLyricsx-0.4.3.dmg`
- `dist/KugouLyricsx-0.4.3-app.zip`（适合放在 GitHub Release）

运行核心逻辑测试：

```sh
make test
```

项目使用 Objective-C、AppKit 和系统自带的 clang 构建，不需要 Python、CocoaPods 或其他包管理器。应用图标的 1024×1024 PNG 母版位于 `Resources/AppIcon.png`，构建时会自动生成 macOS 的 ICNS 图标。

## 工作方式与隐私

应用只在本机读取系统“正在播放”信息、酷狗本地歌词缓存，以及在获得辅助功能授权后读取酷狗公开的当前播放时间标签。它不会读取键盘输入、控制酷狗界面或检查其他应用。找不到本地歌词时，才会把歌曲名和歌手名发送给 `music.163.com` 与 `lrclib.net` 搜索歌词。应用不收集账户、播放历史或个人资料。

播放控制通过随应用打包的 `media-control` 工具发送给 macOS 当前媒体会话。第三方组件的许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 已知限制

- Touch Bar 接口并非 Apple 面向第三方应用公开的正式 API，无法上架 Mac App Store，未来 macOS 更新可能导致失效。
- 当前没有 Apple Developer ID 签名与公证，直接下载时可能出现 Gatekeeper 警告。
- 尚未实现登录时自动启动和独立的图形化设置窗口；歌词偏移目前通过菜单栏滑杆设置。
- macOS 的 Touch Bar 空闲熄灭由系统服务和真实 HID 活动控制；普通第三方应用无法可靠阻止，主屏幕常亮设置不会改变这一行为。
- 播放按钮控制的是 macOS 当前媒体会话；若其他播放器抢占会话，控制对象可能不是酷狗。
- 未授予辅助功能权限时，酷狗窗口位于前台期间无法可靠识别进度条拖动；其余功能仍可使用。
- 在线歌词来自第三方公开接口，接口变化、网络异常或歌曲信息不一致时可能找不到歌词。
- 逐字高亮依赖酷狗本地 KRC 中的逐字标签；没有标签或无法匹配实时文字时会退回整句显示。
- 自适应速度要在一句歌词真实播放结束后才能得到样本，因此第一次出现仍可能略快或略慢；重复段落会逐渐稳定。
- 目前只在一台 Touch Bar Mac 和酷狗音乐 3.3.2 上完成完整播放验证；新版酷狗音乐 20.3.8 已核对媒体数据和本地 KRC 缓存，但尚无 Touch Bar UI 自动化测试。
- Intel Touch Bar Mac 尚未完成真实播放验证。
