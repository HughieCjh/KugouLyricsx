# KugouLyricsx 改名与图标设计

## 发布设计

项目对外名称统一为 `KugouLyricsx`，App、可执行文件、DMG、ZIP、磁盘卷名和 README 使用同一拼写。内部 Objective-C 类继续保留简短的 `KTL` 前缀，避免无意义的大范围代码改名。版本从 0.2.5 升为 0.3.0（构建号 9），同时包含拖动酷狗进度条后歌词重新校准的修复。应用采用新的 bundle identifier；升级时应先退出并移除旧名称 App，避免两个菜单栏进程同时运行。

图标采用原创的深色圆角底板、青紫歌词波形、音符和横向 Touch Bar 光带。它不使用酷狗、LyricsX 或 Apple 的官方标志，既表达音乐与同步歌词，也保持独立项目辨识度。仓库保存 1024×1024 PNG 母版，构建脚本生成 macOS 所需的多尺寸 ICNS。验收包括检查 16、32、128 和 512 像素下的轮廓、App 包内图标资源、Info.plist 标识以及 Finder 显示。

README 新增“与 LyricsX 的关系”，明确本项目不是 LyricsX 插件或修改版，不复制、不依赖 LyricsX 代码；功能体验受到同类 Touch Bar 歌词工具启发。第三方依赖仅为已声明许可的媒体控制组件。发布验证依次执行核心测试、App 构建、签名检查、DMG 挂载检查和产物校验。
